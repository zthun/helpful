# Helpful Reflection

Provides reflection decorators that help describe metadata about a class,
function, or field.

## Installation

```sh
# NPM
npm install @zthun/helpful-reflection
# Yarn
yarn add @zthun/helpful-reflection
```

## Features

Import the public exports in these guides from `@zthun/helpful-reflection`. Use
`import type` for type-only exports.

| Feature                    | Description                                                        |
| -------------------------- | ------------------------------------------------------------------ |
| [tag](./src/tag/README.md) | Attach named tags to classes or members and query them at runtime. |
