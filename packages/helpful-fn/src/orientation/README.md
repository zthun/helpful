# Orientation

[Back to Helpful Functions](../../README.md)

Represent horizontal and vertical layout directions.

## Exports

| Export         | Description                                                        |
| -------------- | ------------------------------------------------------------------ |
| `ZOrientation` | Enum with `Horizontal = "horizontal"` and `Vertical = "vertical"`. |

## Usage

```ts
import { ZOrientation } from "@zthun/helpful-fn";

const direction = ZOrientation.Horizontal; // "horizontal"
```
